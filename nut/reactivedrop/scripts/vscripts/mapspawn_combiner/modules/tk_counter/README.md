# tk_counter

Счётчик тимкиллов, ранги и чат-команды `!tkc*`. Работает на каждой карте через
реестр mapspawn combiner.

Имя в реестре: `tk_counter`. Версия — `version.nut` (`::g_TkVersion`, сейчас 1.4.4).
Тег в чате: `[TKC]`.

`module_tk_counter.nut` подключает ядро в область скрипта `worldspawn` и регистрирует
модуль в `McRegistry`. Счёт, ранги и тексты — в этой же папке. Картинка над морпехом
рисуется клиентским `tk_counter/tkc_popup_hud.nut` из stub-челленджа `weapon_kills`
(отдельного челленджа у тимкиллов нет).

Выключить: `!am_disable tk_counter` — подсчёт, попап и ответы на `!tkc` останавливаются.
Пороги и тексты рангов правятся в `ranks.nut`. Красный текст по центру — в `announce.nut`,
он включается только при `popup 0`. Положение и цвет попапа — `!am_set tk_counter …`,
сохраняется через `!am_save`.

## Файлы

| Файл | Назначение |
|---|---|
| `module_tk_counter.nut` | регистрация, хуки, спавн попапа, `!am_set` |
| `tk_counter.nut` | счёт, сейвы, команды |
| `ranks.nut` | пороги и названия рангов (`::g_TkRanks`) |
| `announce.nut` | шаблон красной строки по центру (`popup 0`) и чат при новом звании |
| `version.nut` | `::g_TkVersion` |

Клиентский Paint (в том же дополнении, что попап оружия):

```
resource/challenges/weapon_kills.txt
scripts/vscripts/tk_counter/tkc_popup_hud.nut
```

Без этого файла на клиенте счёт и `!tkc` работают, попап не рисуется.
`!am_set tk_counter popup 0` возвращает красный `game_text` по центру экрана.

## Как считается

Считается убийство морпеха морпехом. Жертва-бот идёт в счёт. Самоубийство
пропускается. Убийца — морпех под управлением игрока (`IsInhabited`); счёт
пишется этому игроку (`GetCommander`). Бот как убийца в счёт не идёт.

## Что видно на экране

На каждый тимкилл над морпехом-убийцей появляется панель: череп и число.
Она справа от головы (`popup_x` > 0). Несколько тимкиллов подряд у одного
морпеха выстраиваются ещё правее. Слева в той же полосе — попап оружия,
по центру сверху — strange.

Попап видят все, у кого есть клиентский скрипт. `!tkc_off` его не прячет.
Чат при новом звании и красный текст по центру (если попап выключен) видят
только игроки с `notify` 1.

На панели ник и название звания не пишутся. Звание приходит в чат в момент
повышения. Число коротко накручивается (`popup_anim_time`).

Иконка — вырезанный с HUD `DeadIcon` (`materials/vgui/tk_counter/dead_icon`),
тот же Paint, что у попапа оружия (`weapon_kills/wkc_popup_hud.nut`).

## Сейвы

`save/vscripts/tk_counter/` — `index.txt` со списком идентификаторов аккаунтов и по файлу
на игрока. Строка игрока: `счёт|ник|язык|notify`, `notify` это `0` или `1`.

`notify` 1 показывает чат при новом звании и красный текст по центру, когда
`popup` равен 0. `notify` 0 прячет и то, и другое. World-попап от `notify` не зависит.
То же самое делают `!tkc_on` / `!tkc_off`.

Ключ на диске — числовой идентификатор аккаунта Steam. В чате и командах — `STEAM_1:Y:Z`
(как в `status`); принимается и `[U:1:n]`. `STEAM_0` и `STEAM_1` с одним Y:Z
считаются одним аккаунтом.

Язык по умолчанию — `en` (общий `!mc_lang`). Ранг из файла не пишется: его считают
по текущему `ranks.nut` в момент показа.

## Команды `!tkc`

Сообщение должно начинаться с `!tkc`. Алиас `/tkc…` тоже принимается.

| Команда | Кто | Что делает |
|---|---|---|
| `!tkc` | все | свой счёт и ранг |
| `!tkc_top` | все | таблица лидеров |
| `!tkc_next` | все | следующий ранг |
| `!tkc_ranks` | все | список рангов и порогов |
| `!tkc_lang ru\|en` | все | язык рангов (без аргумента — текущий) |
| `!tkc_on` | все | чат о звании и красный текст по центру |
| `!tkc_off` | все | скрыть чат о звании и красный текст по центру |
| `!tkc_test` | админ | попап над своим морпехом, счёт не меняется |
| `!tkc_reset STEAM_…\|all` | админ | сброс игрока или всей статистики |
| `!tkc_help` | все | справка |

`!tkc_reset` и `!tkc_test` проверяют `McAuth.IsAdmin` (тот же список, что у модуля `admin`).
Отдельного списка админов у этого модуля нет.

Подсказка при входе — одна строка модуля `admin` (`!am_help`). Свой tip этот модуль не шлёт.

## Настройки `!am_set`

`!am_vars tk_counter` / `!am_set tk_counter <var> <value>` / `!am_save`.
Менять может админ. Размеры в пикселях при высоте экрана 768, дальше масштаб
экрана и `popup_scale`.

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `popup` | `1` | попап над морпехом (`0` — красный текст по центру) |
| `popup_lifetime` | `3.5` | сколько секунд виден попап |
| `popup_delay` | `0.4` | задержка перед появлением |
| `popup_anim_time` | `0.4` | секунды накрутки числа (`0` — сразу) |
| `popup_x` | `120` | сдвиг X, px @768p (правее головы) |
| `popup_y` | `-20` | сдвиг Y, px @768p (выше головы — отрицательное) |
| `popup_stack_gap` | `72` | шаг стека (как у попапа оружия) |
| `popup_icon_w` / `popup_icon_h` | `32` / `32` | размер черепа (квадрат) |
| `popup_scale` | `1.0` | множитель размера |
| `popup_accent` | `255 70 70` | RGB полоски и черепа |
| `popup_text` | `255 40 40` | RGB числа |
| `popup_bg` | `16 6 8` | RGB фона |
| `popup_bg_alpha` | `225` | альфа фона |
| `popup_alpha` | `230` | альфа черепа и числа |
| `popup_icon` | `vgui/tk_counter/dead_icon` | череп с портрета мёртвого морпеха |

```
!am_set tk_counter popup_x 140
!am_set tk_counter popup_accent 255 70 70
!am_set tk_counter popup 0
```
