# legacy_chat

Старые чат-команды из прежнего `mapspawn.nut`. Один модуль = прежний корневой
`OnGameEvent_player_say`.

Имя в реестре: `legacy_chat`. Версия задаётся в `module_legacy_chat.nut`.

Выключить: `!am_disable legacy_chat`.

Совпадение — точная строка после `tolower()` (без аргументов, кроме `!setleader`).

## Команды

| Команда | Что делает |
|---|---|
| `!koopa` | спавнит крупного груба в точке прицела |
| `!dropnuke` | оглушающая граната над морпехом (кулдаун 10 с) |
| `!cake` | торт на голове игрока `STEAM_1:0:17639821` (один раз за загрузку) |
| `!marechal` | строка в чат |
| `!waterbear` | строка в чат |
| `!vcute` | уменьшает морпеха игрока `STEAM_1:0:42186506` |
| `!hat` | шапка-паразит на своём морпехе |
| `!nohopa` | гранаты винтовки, привязанные к морпеху |
| `!poopa` | блибы бумера у морпеха |
| `!jews` | только `STEAM_1:0:90189985`: радиоактивная бочка на морпехе |
| `!vpotoke` | частицы `gas_trail_small` на глазах игрока `STEAM_1:1:717894133` |
| `!fetushat` | маленькая королева на голове игрока `STEAM_1:1:7396643` |
| `!chuj` | блиб бумера на голове |
| `!friendlyfire` | строка в чат |
| `!sleepyboy` | модель миномёта на спине |
| `!setleader <имя>` | только суффикс SteamID `20522390`: назначить лидера лобби по нику |

`!setleader` не заменяет `!am_leader` модуля `admin`.
