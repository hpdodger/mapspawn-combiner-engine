# laser_pointer

Лазерный указатель в духе DRG: луч от морпеха до прицела, его видят все игроки.
Клиентам достаточно файлов самой игры. Луч останавливается на стенах, врагах
и союзниках. Выстрел при включённом луче может поставить метку (вспышка в точке);
объявление в чат с именем и дистанцией по умолчанию выключено (`mark_chat`).

Имя в реестре: `laser_pointer`. Версия задаётся в `module_laser_pointer.nut`.
Тег в чате: `[LP]`.

Выключить: `!am_disable laser_pointer`. Настройки — `!am_vars` / `!am_set laser_pointer …`
(меняющие команды — список SteamID в `admins.nut`).

## Управление

Луч горит, пока клавиша удерживается, и не дольше `max_hold` секунд
(`!am_set laser_pointer max_hold N`; `0` — до отпускания). Повторный `laser_on`,
пока луч уже включён, таймер удержания не сбрасывает.

Чат `laser` / `!laser` / `/laser` и `scripted_user_func laser` печатают справку.

Удержание:

```
alias +lp "scripted_user_func laser_on"
alias -lp "scripted_user_func laser_off"
bind MOUSE4 "+lp"
```

Нажатие шлёт `laser_on` один раз, отпускание — `laser_off`. Движок не повторяет
команду, пока клавиша зажата. После автовыключения по `max_hold` луч вернётся
только после отпускания и нового нажатия.

Метка без выстрела:

```
bind MOUSE5 "scripted_user_func laser_mark"
```

Жест как в DRG (удержание = луч, отпускание = метка без выстрела):

```
alias +lpm "scripted_user_func laser_on"
alias -lpm "scripted_user_func laser_mark; scripted_user_func laser_off"
bind MOUSE4 "+lpm"
```

В `-` алиасе `laser_mark` должен стоять **до** `laser_off`.

Метка выстрелом: `!am_set laser_pointer mark_on_fire 1`.

Те же бинды печатает `!am_info laser_pointer` в консоль игрока.

При входе в чат приходит подсказка `laser pointer — hold a bound key; !laser for binds`
(один раз на SteamID за карту, задержка 3.5 с, после подсказки `admin`).

## Как рисуется

Всё на стороне сервера, клиентские скрипты не нужны:

- луч — постоянный `env_beam` между двумя маркерами `rd_hud_vscript` (`FL_EDICT_ALWAYS`, невидимая модель);
- метка — вспышка `env_sprite`;
- свечение на конце луча — `info_particle_system` с эффектом `blink`
  (список имён: https://steamcommunity.com/sharedfiles/filedetails/?id=2689066493).

Клиент рисует такие частицы только при `rd_info_particle_system_enabled 1`
(в игре это значение по умолчанию, пишется в `cfg/config.cfg`). Если там `0`,
свечения нет. Луч от этой настройки не зависит. Настройка клиентская: у каждого
игрока своя.

`mark_particles` — отдельный всплеск в момент метки (зависит от карты). Непрерывное
свечение кончика ставится каждый кадр и от `mark_particles` не зависит.

## Переменные

`!am_vars laser_pointer` / `!am_set laser_pointer <var> <value>`:

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `interval` | `0.05` | период обновления, секунды |
| `src_height` | `45` | высота начала луча (`45` — оружие, `60` — голова) |
| `mark_radius` | `64` | запасной радиус поиска цели на конце луча |
| `mark_cooldown` | `1.0` | минимум секунд между метками |
| `mark_duration` | `1.2` | длительность вспышки метки |
| `mark_chat` | `0` | `1` — писать в чат цель и дистанцию |
| `mark_particles` | `0` | `1` — дополнительный всплеск частиц на метке |
| `mark_on_fire` | `0` | `1` — выстрел при активном луче тоже ставит метку |
| `idle_ttl` | `60` | освободить сущности простоявшего игрока через N с (`0` — не трогать) |
| `max_hold` | `3.0` | максимум секунд луча за одно удержание (`0` — до отпускания) |
| `beam_refresh` | `0` | пересоздавать `env_beam` каждые N с, пока включён (`0` — выкл) |
| `beam_width` | `1.5` | толщина луча, сразу на уже созданные |
| `beam_alpha` | `220` | непрозрачность 0–255, сразу |

`Cleanup` на конце миссии уничтожает сущности луча, но помнит, у кого он был
включён, и собирает их снова.
