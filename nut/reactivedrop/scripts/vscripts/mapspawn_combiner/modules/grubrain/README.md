# grubrain

Чат-команда `!grubrain <steamid>` (алиас `/grubrain`): на 2.5 секунды сыпет
личинок `asw_grub` над морпехом указанного игрока. Спавн как у `!koopa`
(`Director.SpawnAlienAt`), после этого личинку поднимают обратно в воздух:
`SpawnAlienAt` сам кладёт сущность на пол.

Пока личинка падает, её держат над морпехом по XY, поэтому при беге колонна
не остаётся сзади. Если морпех умирает — спавн и сопровождение сразу
останавливаются. Уже упавшие личинки остаются. Между вызовами кулдаун
(по умолчанию 15 с).

Имя в реестре: `grubrain`. Версия задаётся в `module_grubrain.nut`.
Тег в чате: `[GR]`.

Выключить: `!am_disable grubrain`. Настройки — `!am_vars` / `!am_set grubrain …`.

SteamID как у `!am_leader`: `STEAM_1:Y:Z`, `[U:1:n]` или числовой идентификатор
аккаунта. Игрок должен быть на сервере и в морпехе.

Ответы об ошибках и кулдауне — только автору команды.
