# spec_lock

Чат-команда `!spec <имя>` (алиас `/spec`): закрепить камеру спектатора на
морпехе до конца сессии.

Имя в реестре: `spec_lock`. Версия задаётся в `module_spec_lock.nut`.
Тег в чате: `[SPEC]`.

Выключить: `!am_disable spec_lock`. На диск `!am_save` выбор игрока не пишет.

## Команды

| Команда | Действие |
|---|---|
| `!spec Vegas` | смотреть за этим морпехом (профиль: Sarge, Wildcat, Faith, Crash, Jaeger, Wolfe, Bastille, Vegas) |
| `!spec <ник>` | смотреть за морпехом этого игрока |
| `!spec auto` | снова как в игре (`off` / `default` / `none` / `clear` / `-`) |
| `!spec` | текущая цель и список живых |

Ответ только автору команды.

Закрепление живёт в памяти VM, ключ — SteamID. Смена карты сохраняет выбор,
выход с сервера его снимает.

`SetSpectatingNPC` из скрипта вызывает `LeaveMarines`, поэтому модуль ставит
камеру только когда у игрока нет живого морпеха. Пока цель жива, `Update`
держит её, даже если игра сбросила хэндл.
