# admin

Управление модулями mapspawn combiner во время игры. Оформлен как остальные
модули: папка, таблица, `McRegistry.Register`. Грузится первым, чтобы им всегда
можно было управлять остальными. Себя выключить нельзя — иначе команды пропадут.

Имя в реестре: `admin`. Версия задаётся в `module_admin.nut`. Тег в чате: `[AM]`.

Движок, реестр и файл настроек — в корневом README репозитория.

## Права

Просмотр (`help` / `modules` / `info` / `vars`) — всем.

Изменения (`enable` / `disable` / `set` / `save` / `load` / `reset` / `leader`) —
список SteamID в `mapspawn_combiner/admins.nut` (`McAuth`). Формат как в `status`:
`STEAM_1:Y:Z`. Тот же список использует `!tkc_reset`.

## Команды `!am_`

Сообщение должно начинаться с `!am_` (голый `am_help` игнорируется).
Алиас `/am_…` тоже принимается (ведущий `/` заменяется на `!`).

Имя модуля — точное, как в `!am_modules` (например `laser_pointer`).

| Команда | Кто | Что делает |
|---|---|---|
| `!am_help` | все | справка |
| `!am_modules` | все | список `[ON]`/`[OFF]` и версии; у себя пометка `(admin)` |
| `!am_info <module>` | все | описание; если у модуля есть `console_info` — печатает его в консоль |
| `!am_vars <module>` | все | переменные модуля |
| `!am_enable <module>` | список SteamID | включить (в памяти, пока не save) |
| `!am_disable <module>` | список SteamID | выключить (в памяти, пока не save) |
| `!am_set <module> <var> <value>` | список SteamID | переменная (в памяти, пока не save) |
| `!am_save` | список SteamID | записать `save/vscripts/mapspawn_combiner/settings.txt` |
| `!am_load` | список SteamID | применить файл (с `OnEnable`/`OnDisable`) |
| `!am_reset` | список SteamID | значения из кода + очистить файл |
| `!am_leader [steamid]` | список SteamID | без аргумента — ник и SteamID текущего лидера; с `STEAM_1:Y:Z`, `[U:1:n]` или числовым идентификатором аккаунта — назначить игрока, который сейчас на сервере |

Префикс `!am_` не пересекается с командами счётчика `!tkc`.

При входе в чат приходит подсказка `mapspawn combiner admin — !am_help`
(один раз на SteamID за карту, задержка 3 с).

## Настройки

Формат файла — в корневом README. Этот модуль его читает и пишет.

- `!am_enable` / `!am_disable` / `!am_set` живут в памяти, пока не сделан `!am_save`.
- После регистрации всех модулей `mapspawn.nut` зовёт `ApplySavedSettings(true)`:
  флаги вкл/выкл без `OnEnable` / `OnDisable`. Ручной `!am_load` уже зовёт эти хуки.
- Сам `admin` из файла не выключается и в файл как выключенный не пишется.
- Автосохранения при переключении нет.

`!am_leader` не заменяет `!setleader` из модуля `legacy_chat`.
